PROYECTO DE PROGRAMACIÓN EN JAVA

Aplicación de Ciclos Repetitivos para la Solución de Problemas

Introducción

La programación es el lenguaje que permite a los humanos comunicarse con las máquinas para resolver problemas del mundo real. Java, uno de los lenguajes más sólidos y demandados, ofrece estructuras potentes como los ciclos repetitivos (for, while, do-while), esenciales para automatizar tareas repetitivas: desde generar tablas de multiplicar hasta procesar nóminas o menús interactivos. En este proyecto aplicaremos análisis, algoritmos y buenas prácticas para construir una solución funcional.

Aplicaciones reales: sistemas de facturación, control de inventarios, simulaciones matemáticas.

Objetivo General

Diseñar e implementar un programa en Java utilizando estructuras repetitivas (ciclos) para resolver un problema planteado, aplicando las etapas de análisis, pseudocódigo, diagrama de flujo, codificación y pruebas, fortaleciendo el pensamiento lógico computacional.

Situación Problema

📌 Contexto: Una institución educativa necesita un programa que permita generar automáticamente las tablas de multiplicar de un número ingresado por el usuario. El sistema debe mostrar los resultados de manera ordenada utilizando ciclos repetitivos. Se requiere una solución clara, con validación y salida formateada.

Actividad 4: Desarrollo del Código en Java

Programa completo usando ciclo for (puedes modificarlo y probar conceptos).

import java.util.Scanner;

public class TablaMultiplicar {
    public static void main(String[] args) {
        Scanner dato = new Scanner(System.in);
        int numero;

        System.out.print("Ingrese un número: ");
        numero = dato.nextInt();

        for(int i = 1; i <= 10; i++) {
            System.out.println(numero + " x " + i + " = " + (numero * i));
        }
        dato.close();
    }
}
