Introducción

La programación es el arte de crear algoritmos que solucionen problemas del mundo real. Java, lenguaje robusto y multiplataforma, es fundamental para desarrollar lógica de software. Los ciclos repetitivos (while, do-while, for) permiten ejecutar bloques de código múltiples veces, automatizando tareas repetitivas como procesar listas, facturas o menús interactivos. Este proyecto integrador aplica todas las etapas del desarrollo: análisis, diseño, codificación y pruebas.

Objetivos

General: Diseñar e implementar una aplicación en Java utilizando ciclos repetitivos para resolver una situación práctica mediante el análisis, diseño y programación de algoritmos.

  • Analizar un problema y definir requerimientos.
  • Diseñar algoritmos y elaborar pseudocódigo.
  • Construir diagramas de flujo.
  • Programar en Java estructuras repetitivas.
  • Realizar pruebas y validaciones.

Diagrama de Flujo

Simbología clave: Inicio/Ovalo → Entrada/Paralelogramo → Decisión/Rombo → Proceso repetitivo (loop) → Salida → Fin.

📌 Espacio para diagrama: El estudiante elaborará su diagrama de flujo en papel o herramienta digital, anexándolo en el entregable.
Estructura: Inicio → Leer opción → ¿Opción=salir? No → Proceso repetitivo (calcular total) → Volver al menú → Sí → Mostrar total → Fin.

Desarrollo del programa en Java

Ejemplo completo usando ciclo do-while para un menú interactivo de ventas:

import java.util.Scanner;

public class ProyectoCiclos {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        double totalVentas = 0;
        int opcion;
        do {
            System.out.println("\n=== MENÚ PRINCIPAL ===");
            System.out.println("1. Registrar venta");
            System.out.println("2. Finalizar y mostrar total");
            System.out.print("Seleccione: ");
            opcion = sc.nextInt();
            if(opcion == 1) {
                System.out.print("Precio del producto: $");
                double precio = sc.nextDouble();
                System.out.print("Cantidad: ");
                int cant = sc.nextInt();
                double subtotal = precio * cant;
                totalVentas += subtotal;
                System.out.println("✔ Producto agregado. Subtotal actual: $" + totalVentas);
            } else if(opcion == 2) {
                System.out.println("💲 Total de ventas del día: $" + totalVentas);
            } else {
                System.out.println("Opción inválida.");
            }
        } while(opcion != 2);
        sc.close();
        System.out.println("Gracias por usar el sistema.");
    }
}

Explicación del código:

  • Scanner: para entrada de datos desde teclado.
  • Variables: totalVentas (double) acumula montos, opción (int) controla ciclo.
  • Ciclo do-while: ejecuta al menos una vez el menú hasta que opción sea 2.
  • Condiciones: si opción=1 calcula subtotal y acumula; si opción=2 termina y muestra total.
  • Salida de datos: mensajes informativos y total final.
