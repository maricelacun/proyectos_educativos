Introducción

El presente proyecto consiste en el desarrollo de un archivo por lotes (.BAT) que implementa un menú interactivo para automatizar tareas comunes en entornos Windows, orientado a la asignatura de Sistemas Operativos y Redes. Los archivos .BAT permiten ejecutar comandos del sistema de forma secuencial, y al integrar un menú con opciones (información del sistema, gestión de procesos, pruebas de red, etc.) se optimiza la administración básica del equipo.

La automatización mediante menús facilita el trabajo a técnicos y usuarios finales, reduciendo errores y ahorrando tiempo en tareas repetitivas. Este proyecto demuestra cómo estructuras condicionales, bucles y comandos de red pueden organizarse en una solución funcional y educativa.

Objetivos

Objetivo General

Diseñar e implementar un script en formato .BAT con un sistema de menú interactivo que permita ejecutar tareas de administración del sistema operativo y diagnóstico de redes, aplicando estructuras de control y bucles.

Justificación

En el ámbito de soporte técnico y administración de redes, gran parte de los diagnósticos iniciales se realizan con comandos de consola. Un archivo .BAT con menú unifica y simplifica estas tareas, siendo accesible incluso para usuarios con conocimientos básicos. Además, el proyecto responde a la necesidad de aplicar teoría de sistemas operativos (gestión de procesos, información del sistema) y redes (ping, configuración IP) en una herramienta práctica.

Valor educativo: Permite comprender cómo funciona el intérprete de comandos, la lógica de bifurcaciones y la reutilización de código batch.

Marco Teórico

Archivo .BAT
Archivo de texto con extensión .bat o .cmd que contiene comandos ejecutables por el intérprete de comandos de Windows (cmd.exe).
Comandos comunes
ECHO, PAUSE, CLS, SET, IPCONFIG, PING, TASKLIST, SYSTEMINFO.
Estructuras condicionales
IF EXIST, IF %var%==valor. Permiten tomar decisiones.
Estructuras repetitivas
Mediante etiquetas :INICIO y el comando GOTO se crean bucles.
Menús interactivos
Se despliegan opciones numeradas, se captura la entrada del usuario con SET /P opcion= y se evalúa con condicionales.

Análisis del Problema

Los técnicos y estudiantes a menudo necesitan ejecutar múltiples comandos de diagnóstico de forma aislada, perdiendo tiempo. El programa resuelve: falta de integración, errores de sintaxis y demoras, centralizando la información del sistema en una sola interfaz.

Desarrollo del Programa

Código fuente completo (SysRedMenu.bat) - 5 opciones

@echo off
title Proyecto SO y Redes - Menú Interactivo
color 0E
:menu
cls
echo ==============================================
echo        MENU PRINCIPAL - SISTEMA .BAT
echo ==============================================
echo  1. Informacion completa del sistema
echo  2. Configuracion IP (ipconfig /all)
echo  3. Prueba de conectividad (ping)
echo  4. Listar procesos en ejecucion
echo  5. SALIR
echo ==============================================
set /p opcion="Elija una opcion (1-5): "

if "%opcion%"=="1" goto info_sistema
if "%opcion%"=="2" goto ipconfig_all
if "%opcion%"=="3" goto ping_tool
if "%opcion%"=="4" goto tasklist_view
if "%opcion%"=="5" goto salir
echo Opcion no valida, intente de nuevo.
timeout /t 2 >nul
goto menu

:info_sistema
cls
echo === INFORMACION DEL SISTEMA ===
systeminfo | findstr /C:"Nombre de OS" /C:"Fabricante" /C:"Memoria" /C:"Procesador"
echo.
pause >nul
goto menu

:ipconfig_all
cls
ipconfig /all
echo.
pause
goto menu

:ping_tool
cls
set /p destino="Ingrese direccion IP o dominio: "
ping %destino% -n 4
pause
goto menu

:tasklist_view
cls
tasklist | more
pause >nul
goto menu

:salir
cls
echo Gracias por usar el programa. Hasta luego!
timeout /t 2 >nul
exit

Explicación de módulos

  • :menu → Bucle principal con opciones.
  • info_sistema → Muestra información del SO.
  • ipconfig_all → Configuración de red.
  • ping_tool → Prueba de conectividad.
  • tasklist_view → Lista procesos activos.
  • salir → Finaliza el script.

Pruebas de Funcionamiento

Se ejecutó el script en Windows 11:

  • Opción 1: Muestra OS, fabricante, procesador y memoria.
  • Opción 2: ipconfig /all muestra IP, máscara, puerta enlace.
  • Opción 3: Ping a google.com responde correctamente.
  • Opción 4: Lista procesos con paginación.
  • Opción 5: Sale sin errores.

Metacognición

¿Qué aprendí?

Aprendí a crear menús interactivos en .BAT con GOTO, IF, SET /P. Dominé comandos como systeminfo, ipconfig, ping y tasklist.

¿Qué fue lo más difícil?

Manejar el flujo con GOTO para que regrese al menú después de cada comando y filtrar la salida de systeminfo con findstr.

¿Qué mejorarías?

Exportar resultados a archivo, validar entradas, colores personalizados y agregar opciones como tracert o netstat.

Aprendizajes clave

  • .BAT son potentes para automatizar tareas.
  • GOTO y etiquetas crean menús interactivos.
  • Es clave validar entradas del usuario.
  • La metacognición ayuda a identificar áreas de mejora.
